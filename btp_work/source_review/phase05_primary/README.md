# Additional Phase 5 references

These are additional primary sources consulted for Phase 5, alongside the seven supplied papers and proposal. The PDFs and page-marked text are stored here; [manifest.json](manifest.json) records their source URLs, SHA-256 checksums and page counts. [references.bib](references.bib) provides citation entries.

| Reference | Local paper and relevant sections | Use in Phase 5 |
| --- | --- | --- |
| Yannick Stade, Wan-Hsuan Lin, Jason Cong and Robert Wille, Routing-Aware Placement for Zoned Neutral Atom-based Quantum Computing (2025) | [PDF](routing_aware_placement_2025.pdf), [text](routing_aware_placement_2025.txt), Sections III-V; [author source](https://www.cda.cit.tum.de/files/eda/2025_iccad_routing-aware_placement_zoned_neutral_atom.pdf), [arXiv](https://arxiv.org/abs/2505.22715) | Placement must consider AOD compatibility and the sum of duration-dominating movements across sequential groups. Its A* and zoned hardware are prior work, not the Phase 5 algorithm or device model. |
| Yannick Stade, Lukas Burgholzer and Robert Wille, Search Smarter, Not Harder: A Scalable, High-Quality Zoned Neutral Atom Compiler (2025) | [PDF](search_smarter_2025.pdf), [text](search_smarter_2025.txt), Sections 2-3; [author source](https://www.cda.cit.tum.de/files/eda/2025_search_smarter_not_harder.pdf) | Motivates bounding storage/search and preserving row/column compatibility. Its relaxed routing is not enabled: Phase 5 retains the established RFT router. |
| Rainer E. Burkard and Eranda Cela, Linear Assignment Problems and Extensions, author manuscript for Handbook of Combinatorial Optimization | [PDF](linear_assignment_review.pdf), [text](linear_assignment_review.txt), Sections 1, 3 and 5; [source](https://www.andrew.cmu.edu/course/42-731/handouts/Burkard_LAP_review.pdf) | Establishes assignment, Hall feasibility and threshold bottleneck matching. Phase 5 minimizes the pair (maximum entry, sum entries), not the entire sorted lexicographic bottleneck vector. No new matching-algorithm novelty is claimed. |
| SciPy reference, linear_sum_assignment | [Official documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linear_sum_assignment.html) | Confirms rectangular sum-assignment semantics. Phase 5 implements an explicit rectangular augmenting-path solver to expose legality and complexity; the original provider remains unchanged. |
