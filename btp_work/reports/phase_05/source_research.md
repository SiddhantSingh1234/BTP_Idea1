# Phase 5 source research and design consequences

Primary sources were reviewed before fixing the assignment design. The original PDFs are immutable, with checksums in [the existing source manifest](../../source_review/manifest.json). Additional papers are kept in [the reference folder](../../source_review/phase05_primary/README.md), including PDFs, page-marked text, checksums and BibTeX. No internship report input was used.

The frozen implementation's first-endpoint materialization mismatch is corrected in every new control. |

| [Device model paper](../../../Papers/1_2607.20616v2.pdf) | Limitations of fixed coupling maps and the current/target geometry needed by shuttling-aware compilation | Assignment acts on explicit sites and declared device capabilities. Additional routing-aware placement work groups compatible moves and charges duration proxies; its zoned architecture and search methods cannot simply be used as direct RFT performance baselines. The later scalable search paper reinforces the need to account for memory and bounded exploration. These observations motivate fixed-size candidate expansion and exact polynomial matrix solves, with no rerouting search or Phase06 repair enabled.

The assignment review distinguishes a bottleneck optimum from a full lexicographically sorted vector objective. Here the specified two-stage objective is exactly (max c, sum c). A bottleneck on composite cost is a surrogate, not a proof of minimum physical makespan/error. The rectangular shortest-augmenting-path implementation has an explicit worst-case bound and no dummy placements.

Development uses independent matrix/physics fixtures and predetermined synthetic seeds. Gamma, horizons, normalizers, weights and expansion are frozen before the held-out routed pilot. Existing QFT5 smoke/Phase04 outcomes check compatibility and correctness only; they are not used to tune weights. Positive, tied, negative and invalid outcomes will all remain in the pilot artifacts.
